## 📦 Kurulum

Projeyi bilgisayarınıza klonlayın ve gerekli kütüphaneleri yükleyin:

```bash
# Projeyi indir
git clone https://github.com/thechecker45/HackerToolsV3.git

# Dizine gir
cd HackerToolsV3

# Gerekli paketleri yükle
pip install -r requirements.txt
```

## 💻 Kullanım

Aracı çalıştırmak için terminale şu komutu girmeniz yeterlidir:

```bash
python HackerToolsV3.py
```

Program açıldığında karşınıza 30 maddelik bir menü gelecektir. İlgili numarayı tuşlayarak istediğiniz aracı kullanabilirsiniz. Çıkmak için menüde `q` tuşuna basmanız yeterlidir.
